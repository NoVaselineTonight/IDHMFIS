# IDHMFIS Keyboard Shortcuts

Open the **Command Palette** (Ctrl+K) for an interactive, searchable reference.

---

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Command palette |
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save project as… |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `F11` | Toggle full-screen laser preview |
| `Escape` | Close overlay / cancel |

---

## Transport

| Shortcut | Action |
|----------|--------|
| `Space` | Play / Pause |
| `Escape` | Stop |
| `Home` | Go to beginning |
| `` ` `` (backtick) | Toggle master blackout |
| `F12` | Take screenshot of preview |

---

## Cue Selection

| Shortcut | Action |
|----------|--------|
| `1` – `9` | Select cue slot 1–9 (cue library focus) |
| `Ctrl+1` – `Ctrl+9` | Activate cue slot 1–9 (immediate, no confirmation) |
| `Enter` | Activate selected cue |
| `Delete` | Delete selected cue |
| `Ctrl+D` | Duplicate selected cue |
| `Ctrl+A` | Select all cues |
| `F2` | Rename selected cue |
| `Ctrl+↑` / `Ctrl+↓` | Move selected cue up / down in cue list |

---

## Navigation

| Shortcut | Action |
|----------|--------|
| `Tab` | Cycle focus between panels |
| `Ctrl+Tab` | Cycle panels in reverse |
| `Ctrl+1` | Focus Cue Library |
| `Ctrl+2` | Focus Laser Preview |
| `Ctrl+3` | Focus Inspector |
| `Ctrl+4` | Focus Timeline |

---

## Timeline

| Shortcut | Action |
|----------|--------|
| `←` / `→` | Move playhead left / right (coarse) |
| `Shift+←` / `Shift+→` | Move playhead by 1 beat |
| `Ctrl+←` / `Ctrl+→` | Move playhead to previous / next cue |
| `K` | Insert keyframe at playhead (selected parameter) |
| `Shift+K` | Delete keyframe at playhead |
| `[` / `]` | Trim cue start / end to playhead |

---

## Parameters

| Shortcut | Action |
|----------|--------|
| `R` | Reset selected parameter to default |
| `Ctrl+Click` on slider | Enter exact value |
| `Alt+Drag` on slider | Fine adjustment (0.001 step) |
| `Double-click` on slider | Reset to default |

---

## Tips

- All shortcuts are rebindable in **Settings → Keyboard Shortcuts**.
- The Command Palette (`Ctrl+K`) lists every action with its current shortcut.
- Shortcuts are disabled while text fields are focused.
- For DMX consoles controlling IDHMFIS: keyboard shortcuts are independent of DMX — you can operate both simultaneously.
